## 2. antd 基建（依赖 / 入口 / 主题 / React 19）

### 2.1 依赖（已安装）

```
antd@^6.4.5            @ant-design/icons@^6.3.1
```

React 19.2 + antd v6 → **原生兼容，不装 v5-patch**。

### 2.2 入口与全局 Provider（`web/src/main.jsx`，唯一改动的现有入口）

```jsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { ConfigProvider, App as AntApp, theme } from 'antd';
import zhCN from 'antd/locale/zh_CN';
import App from './App.jsx';
import AdminApp from './admin/AdminApp.jsx';
import './styles.css'; // 精简后的全局背景/容器

const isAdmin = window.location.pathname.startsWith('/admin');

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <ConfigProvider
      locale={zhCN}
      theme={{
        algorithm: theme.darkAlgorithm,
        token: { colorPrimary: '#4f8cff', borderRadius: 10 },
      }}
    >
      <AntApp>{isAdmin ? <AdminApp /> : <App />}</AntApp>
    </ConfigProvider>
  </StrictMode>,
);
```

### 2.3 message / Modal 用 `App.useApp()`（不要静态方法）

antd v6 + React 19：组件内 `const { message, modal } = App.useApp();`（已被 `<AntApp>` 包裹）。**非组件文件（如 `adminApi.js`）不弹 message**，只抛错，由调用组件捕获后用 `useApp` 弹出——保持分层干净。

## 3. 鉴权与进入（密钥 = `.env` 的 `ADMIN_TOKEN`）

### 3.1 `.env` 配置（需求①）

```ini
# .env —— 必须设一个固定值（留空 = Admin 未启用，后端返回 503）
ADMIN_TOKEN=请改成一段高强度随机串
```
`.env.example` 同步给出示例占位与「留空=未启用」注释。后端 `config.auth.adminToken` 已读取，无需改代码。

### 3.2 进入流程（Token Gate）

```
打开 /admin → 读 localStorage['mcs_admin_token']
  ├─ 无 → <TokenGate>（antd Card + Input.Password + Button）
  │        输入密钥 → GET /api/admin/stats 校验
  │          ├─ 200 → 存 token → 进入；401 → message「密钥无效」；503 → 提示「未配置 ADMIN_TOKEN」
  └─ 有 → 进入主界面；任一请求遇 401 → 清 token → 退回 TokenGate
```
右上「退出」= 清 `localStorage` 回门。无会话过期（与固定密钥语义一致）。

### 3.3 请求层 `admin/adminApi.js`（Bearer + 统一解析 + 401）

```js
const TOKEN_KEY = 'mcs_admin_token';
export const getToken = () => localStorage.getItem(TOKEN_KEY) || '';
export const setToken = (t) => localStorage.setItem(TOKEN_KEY, t);
export const clearToken = () => localStorage.removeItem(TOKEN_KEY);

export class AdminError extends Error {
  constructor(errCode, errMsg, status) {
    super(errMsg || errCode);
    this.errCode = errCode;
    this.status = status;
  }
}

async function request(path, init = {}) {
  const res = await fetch(path, {
    ...init,
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${getToken()}`, ...init.headers },
  });
  let body = null;
  try { body = await res.json(); } catch { /* 非 JSON */ }
  if (res.status === 401) throw new AdminError('UNAUTHORIZED', '密钥无效或已变更', 401);
  if (body && body.errCode === 0) return body.data;
  throw new AdminError(String(body?.errCode ?? 'INTERNAL'), body?.errMsg ?? '服务内部错误', res.status);
}

export const adminApi = {
  stats: () => request('/api/admin/stats'),
  accounts: () => request('/api/admin/accounts'),
  addAccount: (b) => request('/api/admin/accounts', { method: 'POST', body: JSON.stringify(b) }),
  setAccountDisabled: (id, off) => request(`/api/admin/accounts/${encodeURIComponent(id)}/${off ? 'disable' : 'enable'}`, { method: 'POST' }),
  relogin: (id) => request(`/api/admin/accounts/${encodeURIComponent(id)}/relogin`, { method: 'POST' }),
  plans: () => request('/api/admin/plans'),
  upsertPlan: (b) => request('/api/admin/plans', { method: 'POST', body: JSON.stringify(b) }),
  genCodes: (prefix, count) => request('/api/admin/codes', { method: 'POST', body: JSON.stringify({ prefix, count }) }),
  codesByStatus: (status) => request(`/api/admin/codes?status=${encodeURIComponent(status)}`),
  revokeCode: (code) => request(`/api/admin/codes/${encodeURIComponent(code)}/revoke`, { method: 'POST' }),
};
```

## 5. 现有 Web 端（取码页）antd 升级映射

> 原则：**交互与信息架构不变**，只把展示控件换成 antd；`App.jsx` 的 phase 分支与 hooks 调用不动。

| 组件 | 现状（手写） | 升级为 antd |
|---|---|---|
| 容器 | `.app/.card` 深色卡 | `ConfigProvider`(暗色，全局) + `Card`（居中，`max-width:480`） |
| `ApplyCard` | 标题+码片+按钮 | `Typography.Title/Paragraph` + `Tag`(套餐) + `Button type=primary block`(申请) |
| `ActiveCard` | 别名框+倒计时+状态条+spinner+取消 | 别名 `Typography.Text copyable` + 倒计时 `Statistic.Countdown`（或保留 useCountdown+大字）+ 状态条 `Steps` + `Spin`(监听中) + `Button`(放弃)；pending 态用 `Spin`+提示 |
| `MailView` | 验证码高亮+邮件头+text/html tab+iframe | 验证码 `Alert`/`Card`+`Typography copyable` + 邮件头 `Descriptions` + `Tabs`(纯文本/HTML) + **保留 `<iframe sandbox="" srcDoc>`**（见下） |
| `ResultsView` | 回看列表+保留时间 | `List`/`Collapse` 包多条 `MailView` + `Typography.Text type=secondary`(剩余保留) |
| `ExpiredCard` | 超时/取消+重获取 | `Result status="warning"` + `Button`(重新获取) |
| `ErrorCard` | 错误码文案+重试 | `Result status="error"/"warning"`（按 `errorText` 的 kind）+ `Button`(重试) |
| `CopyButton` | 自定义复制按钮 | **删除**，统一用 `Typography.Text copyable` / `Button`+`message` |

**安全红线（不变）**：`MailView` 渲染第三方邮件 HTML **必须**继续用 `<iframe sandbox="" srcDoc={mail.html} referrerPolicy="no-referrer">` 隔离——**antd 无安全 HTML 渲染组件**，仅用 antd 包外层（`Card`/`Tabs`），iframe 内核与 sandbox 属性原样保留，杜绝 XSS。

## 7. 关键实现要点

- **导出** `admin/download.js`：`new Blob([text]) → URL.createObjectURL → <a download>`；`links.csv` 头 `code,link`，`link=${location.origin}/r/${code}`；`codeText=(c)=>typeof c==='string'?c:c.code` 兼容返回形态。
- **套餐数组字段**：`allowedGroups/targetSenders` 用 `Select mode="tags"`（提交即数组，免手工 split/join）。
- **倒计时**：`Statistic.Countdown value={lease.expiresAt} onFinish={...}`；或保留 `useCountdown` 控制 warn/over 配色。二选一，优先 antd `Statistic.Countdown` 减码。
- **401 登出**：各 Tab 请求 `catch`，`if (err.status===401){ clearToken(); 回到 TokenGate }`。

## 9. 安全注意

- 密钥存 `localStorage`（简单够用）；Admin 页不渲染不可信内容，XSS 面小；建议仅可信网络 + 生产 HTTPS。
- 前端日志/报错**不打印 token**；账号视图后端已脱敏（无 `creds_ref`）。
- 邮件 HTML 渲染**坚持 iframe sandbox 隔离**（§5 红线）。
- 503 与 401 区分提示，避免把「未配密钥」误导成「密钥错」。
